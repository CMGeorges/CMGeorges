Démonstration interactive

Un transfert.
Un résultat cohérent.

Essayez un transfert entre deux comptes fictifs. Le débit et le crédit sont calculés ensemble, en centimes entiers. Un solde insuffisant conserve les deux soldes.

Cette interaction illustre un principe utilisé dans les corrections backend : préserver la cohérence des opérations.

Illustration locale uniquement : aucun compte réel, aucun appel bancaire, aucun paiement Stripe. Elle ne remplace pas un test de transaction en base.

Compte A · émetteur100,00 $
Compte B · destinataire25,00 $
Montant positif, deux décimales maximum. Total conservé : 125,00 $.

La simulation est prête.

Lancer CartePro · Python 3.11 / 3.12
git clone -b codex/portfolio-hardening-20261008 https://github.com/CMGeorges/CartePro-portfolio.git
cd CartePro-portfolio
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python run.py

Ouvrir localhost:5000. SQLite est utilisé localement. Les webhooks requièrent vos propres clés Stripe ; consulter le guide pour les cookies et CSRF.
